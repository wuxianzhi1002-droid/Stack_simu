# Zemax NSC 外腔增强型多层膜干涉系统建模任务

========================================================

软件环境
========================================================

使用：

- Zemax OpticStudio
- Non-Sequential Mode (NSC)
- ZOS-API
- Python API

目标：

建立一个用于调焦调平研究的外腔增强型多层膜干涉系统。

系统目标
========================================================

研究：

Reference Reflector
+
Air Gap
+
Film Stack

形成的谐振干涉光谱。

重点分析：

- 干涉fringe
- cavity modulation
- fringe visibility
- 多腔耦合效应
- 调焦调平信号特性

========================================================

# 系统结构

========================================================

系统结构：

        ↓
Air Gap (1 mm)
        ↓
HSQ top surface
        ↓
PSS / Cr
        ↓
SOC
        ↓
TiO2 / HfO2
        ↓
Cu / SiN substrate

========================================================

# 光学参数

========================================================

波长范围：

400nm – 800nm

要求：

高光谱分辨率。

由于：

1mm空气腔会产生极密干涉fringe。

因此：

请采用：

0.01–0.05nm采样。

并检查：

- fringe aliasing
- wavelength undersampling

========================================================

# 光源设置

========================================================

光源：

- Plane Wave
- 垂直入射
- 无限平面近似

偏振：

- TE/TM均考虑
- 若Zemax限制，请说明

=======================================================

# 参考反射面

========================================================

建立：

理想平面部分反射面。

参数：

- Reflectivity = 50%
- 无限平面
- 无粗糙度
- 无散射

用途：

形成外部低精细度Fabry–Perot腔。

请不要：

- 使用高Q cavity
- 使用DBR
- 引入复杂色散镜

========================================================

9. 自动检查机制
========================================================

--------------------------------------------------------
