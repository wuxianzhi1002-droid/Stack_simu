# 悉识膜厚仪细节沟通

## 一句话目标

确认悉识 NanoSense / NS-20 / NS-Micro 是否能在我们的真实复杂多层膜样品上提供可靠的膜厚或材料先验，并明确精度口径、适用边界、样片测试方案和价格配置。

## 0. 电话前准备

- 准备一份我们当前典型膜系的简化说明：基底、层序、名义厚度范围、是否含金属/吸收层/图案区域。
- 准备希望他们测试的 1-2 类代表性样品：平坦区样品、图案区样品。
- 准备已有参考结果：椭偏、工艺名义厚度、XRR/TEM/台阶仪/仿真结果，如目前没有就明确说明。
- 明确我们希望拿到的测试输出：每层厚度、原始光谱、拟合曲线、残差、重复性和参考对比。

## 1. 开场与本次沟通目标

**说明我们正在评估他们的 NanoSense / NS-20 / NS-Micro 系列设备，用于复杂多层膜测量和后续光谱/FP 腔长反演中的膜厚先验。**

**本次最希望先确认三件事：**

1. **设备在我们这类数十纳米至百纳米复杂多层膜上的真实逐层测量能力。**
2. **厂商宣传的亚纳米或 `0.5 nm` 精度到底对应什么样品、什么统计口径、什么模型约束。**
3. **是否可以安排真实样片测试，并输出足够完整的数据用于我们判断。**

可后续再展开的问题：价格、交付、售后、软件授权、自动化集成等。

## 2. 我们的测量需求说明

**样品对象：硅片上的复杂多层薄膜，厚度大多在数十纳米至百纳米级。**

**材料类型可能包括光刻胶、介质膜、硬掩膜、金属或吸收层。**

**部分样品可能有图案区域，因此不能只用大面积均匀薄膜的结果判断适配性。**

**我们希望获得的不只是总膜厚，而是尽可能获得各层膜厚，或者至少得到可用于后续反演模型的可靠膜厚先验。**

**这些膜厚先验会进入我们的光谱/FP 腔长反演模型，用来降低多层膜不确定性。**

可以补充说明：

- 我们不要求一开始就完全自动识别未知膜系，可以接受输入层序、材料、厚度范围作为约束。
- 我们更关心真实样品上的可验证表现，而不是只看 SiO2/Si 标准片指标。
- 如果某些层不可辨识，也希望设备或软件能明确提示，而不是只给一个看似稳定的拟合结果。

## 3. 测量原理与模型

**请他们说明 NS-20 / NS-Micro 对多层膜具体采用什么光学模型。**

重点问题：

- **是否使用 TMM / 光学传输矩阵 / 等效多层反射率模型？**
- **薄膜测量中的“反射率最优化拟合算法”具体拟合哪些参数？**
- **厚膜测量中的 FFT 算法和薄膜拟合算法如何切换？**
- **多层膜反演时是否必须预先输入层数、材料顺序和厚度范围？**
- **是否可以固定某些层，只拟合我们关心的目标层？**
- **软件是否会提示参数强相关、多解或不可辨识情况？**

后续可问：

- 是否支持多角度或偏振信息，还是仅使用垂直入射反射光谱。
- 是否支持同时使用反射率和透射率数据。
- 是否可以导入我们自己的仿真光谱或材料模型进行配方验证。

## 4. 精度、准确度、重复性和稳定性

**这是本次电话最关键部分之一。不要只接受一个“0.5 nm”数字，需要让他们拆开解释。**

必须问清楚：

- **`~0.5 nm` 精度具体是绝对准确度、重复性，还是某种 `1 sigma` 统计口径？**
- **这个指标对应的是单层膜、多层膜，还是 SiO2/Si 标准片？**
- **对应的样品厚度范围、材料类型和层数是多少？**
- **如果是多层膜，是每一层都能达到 `0.5 nm`，还是某个目标层/总厚度达到？**
- **对于 `10-100 nm` 复杂多层膜，他们预期每层能达到什么准确度和重复性？**
- **他们产品手册中基于 SiO2/Si 标准片的准确度、精度、稳定性，如何迁移到我们的真实多层膜？**

需要区分的概念：

- 准确度：测量值和真值之间的偏差。
- 重复性/精度：同一条件下重复测量的离散程度。
- 稳定性：跨日或长期测量均值是否漂移。
- 模型误差：材料 `n,k`、粗糙度、层间相关性导致的系统误差。

可以直接追问：

> 如果同一个点连续测 100 次重复性很好，但模型把某一层拟合错了，这种情况软件如何发现？

后续可问：

- 是否能提供第三方计量对比报告。
- 是否能输出每层厚度的不确定度或置信区间。
- 是否能输出拟合参数相关矩阵。

## 5. 测量案例与案例中的疑问

**请他们解释已发案例中与我们最相关的部分，尤其是多层膜案例。**

重点问题：

- **案例 1 中玻璃基底多层膜有些层的测量值和参考范围差异明显，原因是什么？**
- **这些偏差是因为材料光学常数不准、层间相关性强、参考值不准，还是模型不适合？**
- **该案例是否能代表他们多层膜逐层测量能力的真实边界？**
- **是否有更接近我们需求的案例：Si 基底、`10-100 nm` 多层膜、含硬掩膜/光刻胶/金属或吸收层？**
- **是否有图案区域测量案例，尤其是 `1-200 um` 图案宽度范围内的局部测量？**

希望他们补充提供：

- **匿名化完整报告，包含原始反射谱、拟合曲线、残差、每层结果和参考计量对比。**
- **不是只提供最终厚度表或 GOF。**

后续可问：

- 是否有半导体客户类似应用案例。
- 是否有量产在线测量案例。
- 是否能提供失败案例或不推荐测量的膜系类型。

## 6. 测量范围、光斑与图案区适配

**需要明确 NS-20、NS-20 Pro、NS-Micro 哪个型号最适合我们的样品。**

重点问题：

- **我们的膜厚主要是数十纳米到百纳米，推荐哪一款型号和谱段配置？**
- **NS-20 标准光斑约毫米级，是否会平均掉图案区差异？**
- **NS-20 Pro 的小光斑和 NS-Micro 的显微光斑分别能做到多少？**
- **小光斑下精度、重复性、信噪比是否会比标准光斑下降？下降多少？**
- **如果图案尺寸在 `1-200 um`，他们建议用 NS-Micro 还是其他方案？**
- **光斑大小、物镜倍率、NA、工作距离、谱段范围之间有什么限制？**

后续可问：

- 是否能做 mapping。
- 自动平台的点位精度如何。
- 是否适合 wafer 级多点测量。

## 7. 材料库与未知材料处理

**我们需要确认设备能否处理光刻胶、硬掩膜、金属/吸收层等材料。**

重点问题：

- **材料库中是否包含我们可能使用的光刻胶、HSQ/SOC、SiO2、TiO2、HfO2、Cr、Cu、SiN、硬掩膜材料等？**
- **材料库中的 `n,k(lambda)` 来源是什么，是否能查看和导出？**
- **是否支持导入客户自定义 `n,k(lambda)`？格式是什么？**
- **未知材料时，是拟合材料参数，还是必须先用椭偏仪/其他方法建立材料模型？**
- **如果材料 `n,k` 不准，软件如何避免用错误膜厚去补偿材料误差？**

后续可问：

- 材料库是否收费或随软件更新。
- 是否支持 Cauchy、Lorentz、Drude、Tauc-Lorentz 等色散模型。
- 是否可以由他们帮忙建立专用材料模型或配方。

## 8. 软件、数据导出和可追溯性

**我们需要原始数据和拟合过程可追溯，不能只拿最终厚度数字。**

重点问题：

- **是否能导出原始反射光谱 CSV，包括波长数组和反射率？**
- **是否能导出暗场、参考谱、归一化后的反射率？**
- **是否能导出拟合曲线、残差、GOF、每层厚度和拟合参数？**
- **是否能保存完整 recipe，包括层结构、材料库版本、参数边界和固定/自由参数设置？**
- **是否能批量导出多个测点数据，用于我们后续在 Python 中分析？**

后续可问：

- 是否有 API、SDK 或自动化接口。
- 是否支持远程控制或与产线系统集成。
- 软件授权方式是永久授权还是年费。

## 9. 样片测试方案

**建议电话中明确提出真实样片测试，这是判断适配性的关键。**

希望确认：

- **是否可以安排我们提供真实样片进行测试？**
- **测试前他们需要我们提供哪些信息：层序、材料、名义厚度、测点位置、图案尺寸、参考结果？**
- **能否同时用 NS-20/NS-20 Pro 和 NS-Micro 做对比？**
- **测试报告能否包含原始谱、拟合曲线、残差、重复性统计和每层结果？**
- **能否对同一点连续测量，给出短期重复性？**
- **能否取下重放多次，给出装夹/定位误差？**
- **能否测多个点，给出样品空间均匀性或图案区差异？**

建议我们提出的最小测试矩阵：

| 测试项 | 目的 |
|---|---|
| 平坦大面积区域单点重复测量 | 看短期重复性 |
| 同一点取下重放测量 | 看装夹和定位误差 |
| 中心/四角或多个 die 测点 | 看 mapping 和空间差异 |
| 图案区与 open 区对比 | 看光斑平均和图案适配 |
| 与已有参考结果对比 | 看绝对准确度和模型误差 |

后续可问：

- 测试是否收费。
- 测试周期多久。
- 是否可以到现场演示。

## 10. 与我们 FP 腔长反演模型的关系

**需要说明我们不是只做膜厚计量，膜厚结果后续会进入光谱/FP 腔长反演模型。**

重点问题：

- **他们设备输出的膜厚结果是否适合作为膜厚先验，而不是绝对真值？**
- **能否给出每层不确定度范围，方便我们在模型中设置 bounds 或 prior？**
- **能否提供原始反射谱，让我们和本地 TMM/StackRT 模型做 forward-model mismatch 检查？**
- **如果我们有 1 mm 级空气腔或外部参考反射结构，他们是否有相关测量经验？**
- **他们厚膜/FFT 算法是否能处理 1 mm 级 OPD 的密集条纹？对应光谱采样间隔是多少？**

这部分可以明确但不必展开太深：

- 目前主要目标还是评估膜厚/材料先验能力。
- 1 mm 外腔 FP 解算能力属于更进一步问题，电话中先确认他们有没有经验和数据。

## 11. 价格、配置和商务问题

**需要先拿到大致价格区间，判断后续是否值得深入送样和方案设计。**

重点问题：

- **NS-20、NS-20 Pro、NS-Micro 的大致价格区间分别是多少？**
- **UV、NIR、UVX、IRX 不同谱段配置价格差异是多少？**
- **小光斑探头、显微模块、自动平台、AI+ 算法包是否单独收费？**
- **软件、材料库、算法包是永久授权还是年费？**
- **高校科研采购是否有优惠或试用政策？**
- **交付周期、安装培训、保修年限和售后响应如何？**

后续可问：

- 是否支持租用、试用或阶段性采购。
- 是否支持定制配方或定制算法开发。
- 后续升级谱段或模块的成本。

## 12. 电话结束前需要确认的输出

**请他们电话后提供一份针对我们需求的推荐配置和技术方案。**

**请他们提供正式报价或至少价格区间。**

**请他们确认是否能做真实样片测试，以及测试需要的样品和信息清单。**

**请他们提供一份示例完整测试报告，最好包含原始谱、拟合曲线、残差和参考计量对比。**

**请他们明确哪些类型的膜系他们有信心测，哪些风险较高。**

## 13. 我们内部判断标准

电话和样片测试后，建议按以下标准判断：

| 判断项 | 通过标准 |
|---|---|
| 真实样品逐层准确度 | 与参考计量结果偏差可接受，不只是 GOF 好 |
| 重复性 | 同点连续测量和重装夹测量稳定 |
| 图案适配性 | 光斑不会明显平均掉目标区域差异 |
| 数据可追溯性 | 能导出原始谱、拟合曲线、残差和 recipe |
| 材料模型 | 能导入或建立我们自己的 `n,k(lambda)` |
| 不确定度 | 能给出结果可信度或至少说明不可辨识风险 |
| 成本 | 价格、模块、软件授权和维护成本可接受 |

阶段性判断口径：

> 悉识设备优先被评估为膜厚/材料先验工具和局部验证工具；是否能进一步支持我们的 FP 腔长反演，要看真实样片测试、原始光谱导出能力和 1 mm 级外腔相关验证。
