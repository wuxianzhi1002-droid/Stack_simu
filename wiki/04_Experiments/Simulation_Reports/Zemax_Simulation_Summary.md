# Zemax NSC 外腔增强型多层膜系统仿真总结报告

## 1. 仿真目的
本仿真的核心目标是在 Zemax 非序列（NSC）环境下，复现并增强原有的 Lumerical STACK 膜层干涉模型，重点研究以下物理现象：
*   **外腔增强干涉**：建立 50% 参考反射面与多层膜堆栈之间的 **1.0 mm 长空气腔**。
*   **高频条纹解析**：分析由长空气腔产生的极密干涉条纹（FSR 约 0.08nm - 0.32nm）。
*   **方案对比**：在相同外腔条件下，对比 **PSS 导电层方案**与 **金属 Cr 方案**在 400nm-800nm 波段的反射光谱差异。
*   **应用背景**：为半导体设备中的调焦调平（Autofocus/Leveling）感测信号提供高精度的物理仿真支撑。

## 2. 仿真步骤
### A. 资产准备 (Material Assets)
1.  **材料色散模型**：将 HSQ, SOC, PSS 等自定义 Cauchy 色散参数翻译为 Zemax 玻璃库文件（`.AGF`）。
2.  **膜层结构定义**：将多层膜结构（TiO2/HfO2, SOC, PSS/Cr, HSQ）定义为标准 Zemax 膜层格式（`.DAT`）。
3.  **自动化安装**：编写 `install_zemax_assets.py` 脚本，实现资产与 Zemax 系统目录的自动同步。

### B. 系统建模 (NSC Modeling)
1.  **API 连接**：基于官方 ZOS-API 样板，实现 Standalone 独立运行模式。
2.  **几何构建**：
    *   **Source Ray**：准直单射线光源，设置分析光线数为 1000 条。
    *   **Reflector**：使用 `Rectangular Volume` 建立 50% 理想反射面。
    *   **Substrate**：使用 `Rectangular Volume` 建立 Silicon 衬底。
    *   **Detector**：建立 `Detector Rectangle` 接收反射信号。
3.  **腔体配置**：通过设置 `ZPosition` 建立精确的 1mm 空间传播路径。
4.  **物理属性**：在 Substrate 的 **Face 1** 上动态挂载目标膜层（Coating）。

### C. 计算与导出 (Execution)
1.  **高分辨率扫描**：采用 **0.01nm 步长**，全波段共 **40,001 个采样点**，以避免干涉混叠。
2.  **相干追迹**：开启 `Split Rays` 和 `Use Polarization`，确保相干光振幅叠加的准确性。
3.  **结果导出**：逐波长采集探测器功率，导出为 CSV 格式。

## 3. 仿真结果 (初步验证)
*   **模型正确性**：通过 `build_system_only.py` 验证了 3D 布局的合理性，解决了早期版本中物体面积为 0 和坐标重叠的问题。
*   **数据有效性**：在 1nm 粗采样的测试运行中，已成功获得非零的反射率数据，证明光路已连通且膜层属性已生效。
*   **工程产出**：生成了完全自动化的 `zos_automation_final.py` 脚本，可一键生成 `.zmx` 工程和 CSV 数据。

## 4. 仿真问题与解决方案
| 序号 | 遇到的问题 | 根本原因 | 解决方案 |
| :--- | :--- | :--- | :--- |
| 1 | `ModuleNotFoundError` | 脚本运行目录与根目录模块位置不匹配 | 动态修改 `sys.path` 自动包含项目根目录 |
| 2 | 枚举转换报错 | PythonNET 3.0+ 不支持整数隐式转 Enum | 采用 `type(prop)(value)` 的动态类型推断机制 |
| 3 | 反射率为 0 / 空模型 | 物体无 X/Y 面积且坐标设置属性错误 | 改用 `Rectangular Volume` 并使用 `.ZPosition` 属性 |
| 4 | 结果无干涉条纹 | 0.1nm 采样率低于条纹 Nyquist 频率 | 将采样精度提升至 0.01nm (4,0001点) |
| 5 | 计算耗时过长 | NSC 相干追迹计算开销大且采样点极多 | 引入后台静默运行模式及进度实时上报机制 |

## 5. 建议与思考
1.  **模型验证先行**：由于 40,001 点的仿真极度耗时，**务必在每次大规模计算前先运行 `build_system_only.py`**，并在 Zemax GUI 中人工确认 3D 结构、间距和膜层挂载是否完全符合预期。
2.  **计算资源优化**：如果未来需要更密集的参数化分析（如改变 Air Gap 长度），建议将仿真任务拆分为多个波段并行运行，或探索使用 Zemax 的 `IAS_CoatingAnalysis` 接口（如果 3D 遮挡不是主要矛盾）。
3.  **相干性考量**：目前模型假设光源是完全相干的平面波。在实际调焦调平系统中，光源可能具有一定的光谱带宽或空间相干性限制，未来可在光源属性中引入相干长度参数。
4.  **可视化集成**：建议下一步开发一个自动绘图脚本，直接读取 `results_final/` 下的 CSV 文件，并与 Lumerical 的结果进行叠图对比，验证跨软件仿真的物理一致性。
