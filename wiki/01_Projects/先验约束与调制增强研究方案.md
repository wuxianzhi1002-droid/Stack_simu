# 先验约束与调制增强研究方案

## 一句话结论

当前建议采用：

> 顶面高度粗先验 `<= 10 nm` + 膜层工艺百分比先验 + 调制光谱增强 + PCA/MLP 残差补偿

目标是验证：在多层膜扰动下，能否利用有限先验把 FP 腔长解锁定到正确非模糊区域，并进一步把腔长误差补偿到 nm 级。

## 研究问题

最新组会记录提出了两个关键约束：

1. 顶面高度先验误差控制在 `10 nm` 以内。
2. 膜层先验误差应按照工艺百分比计算，而不是写成统一的固定 nm 误差。

因此研究问题收敛为：

> 在顶面高度粗先验误差不超过 `10 nm` 的条件下，不同工艺百分比膜厚扰动会如何影响谱域 FP 腔长的非模糊定位、FFT 粗解误差和 ML 残差补偿效果？

## 方案主线

```text
多层膜名义结构
      ↓
按工艺百分比采样真实膜厚
      ↓
StackRT 生成静态/调制光谱
      ↓
FFT 得到 L_fft 与候选峰
      ↓
顶面高度先验 <=10 nm 约束搜索窗口
      ↓
PCA50 + MLP 学习 delta_L_nm
      ↓
输出 L_pred、非模糊锁定成功率、误差分布和失效条件
```

## 先验建模方式

### 1. 顶面高度先验

按用户当前约束，顶面高度先验误差设为：

```text
H_prior = H_true + eps_H
eps_H ~ Uniform(-10 nm, +10 nm)
```

使用 uniform 分布的原因：

- 它代表最坏边界内的等概率不确定性。
- 比 Gaussian 更保守。
- 便于直接回答“10 nm 以内是否足够锁定非模糊区域”。

可选补充实验：

```text
eps_H ~ Gaussian(0, 3 nm), clipped to ±10 nm
```

该补充实验用于模拟实际测量设备在稳定工作时的集中误差，但不作为主结果。

### 2. 膜层工艺百分比先验

每一层膜厚按百分比扰动：

```text
d_true_i = d_nom_i * (1 + eps_i)
eps_i ~ Uniform(-p_i, +p_i)
```

其中 `p_i` 不统一取值，而按工艺类型设定。

## 膜层百分比扰动建议

下表是第一轮仿真的推荐取值。它不是最终工艺结论，而是基于公开资料建立的可解释先验范围。

| 膜层/工艺类型                                | 建议主仿真 |         压力测试 | 依据                                                                                                                            |
| -------------------------------------- | ----: | -----------: | ----------------------------------------------------------------------------------------------------------------------------- |
| 光刻胶、HSQ、PSS、SOC 等 spin-coated 有机/无机旋涂层 | `±1%` | `±3%`, `±5%` | 先进光刻中为保证良率，旋涂胶厚均匀性要求可到 `±1%`；一般旋涂胶膜厚可精确、可重复调节，但图形/纹理基底会恶化均匀性                                                                  |
| TiO2、SiO2、Al2O3、HfO2 等 ALD/PEALD 氧化物   | `±1%` |        `±2%` | Fraunhofer IOF 报道 200 mm 区域内 ALD 非均匀性：Al2O3 `±0.3%`、TiO2 `±0.8%`、SiO2 `±0.6%`；Oxford Instruments 给出 200 mm wafer 典型均匀性 `<±2%` |
| Cu、Cr 等 PVD/溅射金属层                      | `±2%` |        `±5%` | Cornell CNF 的 AJA 溅射系统在旋转沉积时 4 inch substrate 可遇到 `<1%` uniformity；没有具体设备规格时，应保守放宽                                            |
| 未知或未校准工艺层                              | `±5%` |       `±10%` | 用作保守上界，不作为工艺事实                                                                                                                |

如果后续拿到本实验室工艺报告、椭偏仪 mapping、台阶仪或 XRR/TEM 结果，应优先用本地统计值替换上表。

## 引用依据

### Spin coating / photoresist

- Liu 等关于半导体光刻旋涂建模的综述指出，随着工艺节点缩小，photoresist film thickness uniformity 是关键质量指标；为保持高良率，均匀性需要保持在 `±1%` 内。  
  来源：[Spin coating in semiconductor lithography: Advances in modeling and future prospects](https://www.sciencedirect.com/science/article/abs/pii/S0167931725000152)

- MicroChemicals 的 photoresist spin-coating application note 指出，旋涂得到的胶膜通常平滑、厚度可准确且可重复调节，并且在圆形 wafer 上具有较好厚度均匀性；但纹理基底会降低厚度均匀性。  
  来源：[Spin-coating of Photoresists - MicroChemicals](https://www.microchemicals.com/dokumente/application_notes/spin_coating_photoresist.pdf)

### ALD / PEALD oxide films

- Fraunhofer IOF 报道 PEALD 工艺在 200 mm 区域内的膜厚非均匀性为：Al2O3 `±0.3%`、TiO2 `±0.8%`、SiO2 `±0.6%`。  
  来源：[ALD research reports - Fraunhofer IOF](https://www.iof.fraunhofer.de/en/competences/coating-and-surface-functionalization/ald-research-reports.html)

- Oxford Instruments 的 ALD 技术页给出 200 mm wafer 上典型均匀性 `<±2%`，可作为更保守的 ALD 压力测试上限。  
  来源：[Atomic Layer Deposition - Oxford Instruments](https://plasma.oxinst.com/technology/atomic-layer-deposition)

### PVD / sputter films

- Cornell CNF 的 AJA sputter deposition 工具说明指出，在旋转沉积条件下，4 inch substrate 上可遇到 `<1%` uniformity。该值是特定设备和条件下的参考，不应泛化到所有溅射系统。  
  来源：[Thin Film Deposition - Cornell CNF Users](https://www.cnfusers.cornell.edu/Thin%20Film%20Deposition)

### 顶面高度与 level sensor 参考

- TWINSCAN 相关 SPIE 论文描述了在 measurement station 预先测量 wafer surface height map，再用于 exposure station 聚焦/调平的流程，并报告 focus measurement reproducibility 约 `25 nm` 量级。这里不能直接作为本方案 10 nm 先验的证明，但可作为“高度先验/height map 参与曝光调平”的工程参考。  
  来源：[Performance Results of a New Generation of 300 mm Lithography Systems](https://fab.cba.mit.edu/classes/865.24/topics/mechanical_design/mechanical_design/precision-frontier/performance-results-of-300mm-litho.pdf)

### 椭偏仪定位

- J.A. Woollam 教程指出，椭偏仪常用于 sub-nm 到数 micron 膜厚范围；Purdue FAQ 也说明椭偏仪对超薄膜厚变化具有很高灵敏度。这里将椭偏仪定位为“膜厚先验来源之一”，不把它的误差固定写成 `10%`。  
  来源：[J.A. Woollam Thin Film Thickness](https://www.jawoollam.com/resources/ellipsometry-tutorial/thin-film-thickness), [Purdue Ellipsometry FAQ](https://www.chem.purdue.edu/ric/docs/Gaertner-Ellipsometer-Handout-1---Ellipsometry-FAQ.pdf)

## 仿真实验设计

### 实验 A：非模糊区域锁定能力

目的：

> 验证 `<=10 nm` 顶面高度先验是否足以锁定正确 FP 腔长区域。

变量：

- `eps_H`: `Uniform(-10 nm, +10 nm)`
- `p_spin`: `±1%`, `±3%`, `±5%`
- `p_ALD`: `±1%`, `±2%`
- `p_PVD`: `±2%`, `±5%`

输出：

- 非模糊锁定成功率。
- 锁错峰比例。
- `|L_fft - L_true|` 分布。
- 膜层扰动百分比与腔长误差的关系。

判据建议：

```text
lock_success = selected_peak belongs to true cavity basin
or |L_selected - L_true| < threshold_nm
```

第一轮 threshold 可设为：

```text
threshold_nm = 10 nm
```

因为顶面先验本身为 `±10 nm`，若 FP 粗解无法在该范围内稳定落入正确区域，则该先验不足以支撑非模糊定位。

### 实验 B：调制是否增加可辨识信息

针对宽带光源，$\lambda = 200-600nm$ 。

#### 强度调制

可采用声光调制器、电光调制器，实现

$$I(t) = I_0(\lambda)[1+mcos(\Omega t)]$$
#### 相位调制

$E(\omega,t) = E_0(\omega)e^{i\phi(t)}$ 

无法做到对所有400nm带宽内的频率产生相同相位调制

#### 可能的调制方法：宽带采集+时间调制

施加时间调制：$I(\lambda,t)$，其中$d(t) = d_0+Asin(\omega t)$，也就是只调制腔长。然后做**锁相提取**

目的：

> 验证小幅腔长调制是否比单帧静态光谱更利于腔长解算。

建议先做 PZT/机械等效腔长调制，不先做 AOM 外差。

调制模型：

$$L(t) = L0 + A_{mod} * sin(2π f t)$$

```

第一轮参数：

| 参数 | 建议值 |
|---|---:|
| `A_mod` | `20 nm`, `50 nm`, `100 nm`, `200 nm` |
| `N_frames` | `8`, `16`, `32` |
| `f` | 任意固定值；离线仿真中只需要相位覆盖，不先讨论实时采样 |

比较对象：

- 单帧静态光谱。
- 多帧调制光谱直接拼接 PCA。
- 调制光谱提取轨迹特征后再 MLP。

输出：

- `MAE/RMSE/P95Abs/MaxAbs`
- 锁错峰比例。
- 对膜层百分比误差的鲁棒性。

### 实验 C：PCA50 + MLP 残差补偿

沿用已有最好 baseline：

```text
input = L_fft_um + film_nominal_nm + PCA50(spectra_norm_ds)
target = delta_L_nm = (L_true - L_fft) * 1000
```

约束：

- `film_true_nm` 不可作为主模型输入。
- `cavity_true_um` 不可作为模型输入。
- PCA 只能在 train set fit。
- train/val/test 必须按 `process_id` 划分。

需要比较：

| 模型 | 输入 |
|---|---|
| FFT-only | `L_fft_um` |
| scalar baseline | `L_fft_um + film_nominal_nm` |
| PCA50 + MLP | `L_fft_um + film_nominal_nm + PC1~PC50` |
| modulation PCA + MLP | `L_fft_um + film_nominal_nm + modulation_features` |

### 实验 D：真实扰动鲁棒性

先做第一轮最小扰动集：

- 光源强度缩放。
- 光源谱形 tilt / center shift。
- 加性背景。
- detector noise。
- wavelength calibration shift。
- spectrometer resolution variation。

输出：

- 每类扰动单独加入时的误差退化。
- 多扰动组合时的误差退化。
- 最敏感扰动排序。

## 第一阶段执行顺序

### Step 1：先不改模型，只改数据生成逻辑

把膜层扰动从固定 nm 改为百分比：

```python
film_true_nm = film_nominal_nm * (1 + uniform(-p, p))
```

并在数据集中保存：

```text
film_prior_percent
film_delta_percent
film_nominal_nm
film_true_nm
```

注意：`film_true_nm` 只能用于标签分析和 oracle 对照，不能作为主模型输入。

### Step 2：加入顶面高度先验字段

保存：

```text
H_true_nm
H_prior_nm
H_prior_error_nm
H_prior_bound_nm = 10
```

第一轮可以把 `H_true_nm` 与 `cavity_true_um` 的关系写清楚；如果当前模型没有独立 top height 概念，则先定义为“用于约束 FP 搜索窗口的腔长粗先验”。

### Step 3：跑静态光谱 baseline

先回答：

> 在 `eps_H <= 10 nm` 且膜层百分比扰动下，静态光谱 + PCA50 是否仍能达到稳定补偿？

### Step 4：再跑调制光谱

只有 Step 3 稳定后，再比较调制是否增加信息量。

## 当前应避免的做法

- 不要把所有膜层厚度输出作为主目标。已有实验显示 true thickness oracle 对最终腔长提升有限。
- 不要把膜层误差写成统一 `±10 nm`。这会对薄膜和厚膜产生不合理权重。
- 不要把椭偏仪误差固定写成 `10%`。应把椭偏仪作为膜厚先验来源之一，具体精度依赖膜系、模型和标定。
- 不要直接把 ASML/TWINSCAN 的指标搬到本系统。只能作为 level sensor / height map 工程参考。
