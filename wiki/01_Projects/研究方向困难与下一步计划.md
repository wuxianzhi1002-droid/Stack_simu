# 研究方向、困难点与下一步计划

## 一句话结论

你的当前研究主线可以概括为：

> 面向先进光刻/精密调平场景，在多层薄膜、光刻胶和复杂回光干扰条件下，利用宽带谱域干涉、StackRT/TMM 正向仿真和机器学习残差补偿，从耦合光谱中提取可部署的表面高度/腔长信息，并探索光谱共焦绝对定位与 FP 干涉精测的混合测量方案。

更具体地说，你不是在单纯做一个仿真脚本，而是在回答一个系统级问题：

> 当光谱中同时混有空气腔、薄膜层、材料色散、界面反射、入射角、噪声和真实工艺扰动时，能否稳定提取“上表面高度”这个单一目标量？

## 当前研究方向

### 1. 多层膜谱域干涉正向建模

已有仓库以 `STACK_simu` 为核心，围绕 Lumerical `stackrt`、FDTD、Zemax、MATLAB 验证和 Python 后处理建立了正向仿真链路。

主要关注点：

- 宽带光从空气入射到多层膜时的反射/透射光谱。
- 空气腔长、膜层厚度、折射率色散和界面反射率对谱域 FP 干涉峰的影响。
- `λ -> k` 重采样、FFT 解算、峰检测和腔长误差之间的关系。
- Lumerical StackRT、FDTD、Zemax 和 MATLAB 之间的参数口径一致性。

对应路径：

- `../../work/01_simulation_models/01_Lumerical_Workflow/`
- `../../work/01_simulation_models/02_Zemax_Workflow/`
- `../../work/01_simulation_models/03_MATLAB_Validation/`
- `../../work/02_analysis_code/stackrt_zemax_compare.py`

### 2. 膜层扰动下的腔长残差补偿

从组会材料和 ML 报告看，当前机器学习方向不是“从光谱直接预测全部物理量”，而更像是：

```text
FFT 物理粗解 L_fft
        +
名义膜厚 film_nominal_nm
        +
归一化光谱特征 PCA / CNN
        ↓
预测 residual: delta_L_nm
        ↓
L_pred = L_fft + delta_L_pred
```

这个路线比较稳，因为它把物理模型作为 baseline，让网络只学习 StackRT 多层膜误差造成的残差。

已有关键事实：

| 证据 | 结果 | 含义 |
|---|---:|---|
| 仅标量特征 `L_fft_um + film_nominal_nm` | MAE 约 `11.89 nm` | 标量特征能补偿一部分误差，但难以区分同一 nominal 下的真实膜厚扰动 |
| PCA50 光谱特征 + MLP | MAE 约 `1.32 nm`, RMSE 约 `1.73 nm` | 归一化光谱确实携带了 scalar 之外的扰动信息 |
| PCA100 光谱特征 + MLP | MAE 约 `1.58 nm` | 更多 PCA 分量没有必然改善，PCA50 是更好的优先 baseline |
| true thickness oracle 对照 | MAE 从 `1.390 nm` 到 `1.208 nm` | 真实膜厚作为输入带来的上限收益很小，不值得把“膜厚全反演”作为当前主目标 |
| CNN-small adaptive-k | MAE 约 `5.87 nm` | CNN 有潜力，但当前还没有超过 PCA50 + MLP |

对应路径：

- `../../work/03_ml_inverse_modeling/ML try/`
- `../04_Experiments/ML_Runs/residual_mlp_simple_pca_20260623_161143.md`
- `../04_Experiments/ML_Runs/residual_mlp_simple_pca_limit_20260630_014334.md`
- `../04_Experiments/ML_Runs/CNN_spectral_cnn_cnn_small_adaptive_k_20260624_130415.md`

### 3. 混合型双通道高度测量方案

`最终方案.md` 和相关评审文档里形成了一个更系统的工程设想：

- 光谱共焦/色散共焦通道：提供无模糊绝对高度、粗定位和重捕获。
- FP/谱域干涉通道：提供高灵敏增量测量和 nm 级甚至更高精度潜力。
- 频域分离和模型补偿：处理薄膜短腔、长空气腔、寄生反射和多界面回光。

这个方向适合作为论文或方案论证的“系统架构候选”，但目前仍需要用当前 StackRT/ML 结果来支撑其中的关键 claim。

建议暂时把它表述为：

> 基于仿真和算法验证的混合型高度传感候选方案。

不要过早写成“已经证明可实现的完整工程系统”。

## 主要困难点

### 1. 单一高度量被多层膜信号耦合污染

组会 PDF 第一页提出的核心问题是“从复杂耦合信息中如何提取单一耦合量”。这正是当前研究最本质的困难。

复杂性来自：

- 空气腔长引起长 OPD 干涉峰。
- 光刻胶、HSQ、PSS、SOC、TiO2、Cu 等界面带来多界面反射。
- 薄膜真实厚度偏离 nominal 后，谱峰位置、强度、相位都会变化。
- 低 OPD 薄膜项和高 OPD 空气腔项有时可以频域分离，有时会以相位偏置形式混入长腔峰。
- 掠入射或有限光斑情况下，StackRT 的平面波等效反射结果不能直接给出光斑质心、光斑形状和横向偏移。

当前结论：

> 不能只靠“找最大峰”或单一 FP 公式解决。必须把多层膜正向模型、FFT 峰归属、光谱特征和残差补偿结合起来。

### 2. 绝对高度真值难以获得

06/24 组会记录和 PDF 后半部分都把“真实数据如何获得”列为核心问题。

候选方法各有问题：

| 方法 | 价值 | 局限 |
|---|---|---|
| 白光干涉 | 可测表面形貌 | 仍会受薄膜干扰，不一定给出目标上表面绝对高度 |
| 频率扫描干涉 | 可做高精度距离 | 系统搭建和速度压力较大 |
| 激光三角测量 | 可作为工程参考 | 自身也有膜层 ASD 和几何误差 |
| TEM 截面 | 可测膜层厚度 | 成本高、破坏性、样本少，不直接给出光斑平均高度 |
| AFM | 可提供 0.2-1 nm 级局部高度参考 | 慢、成本高，需要裸硅参考或小空气腔样品 |
| 椭偏仪 | 可间接标定膜厚 | 需要先验模型；04/29 组会记录另提到“每一层厚度的测量误差值：10%左右”，但未明确该数值对应的测量方法、膜系和建模条件，应作为待确认信息，不作为椭偏仪通用误差结论 |

当前判断：

> 仿真数据可以做模型预训练和机制验证，但必须规划少量真实标定集，否则无法说明方法在真实 wafer、真实光源和真实探测器下仍然有效。

### 3. 仿真到真实环境的域差距

组会记录已明确列出真实扰动：

- 光源强度缩放。
- 光源谱形变化。
- 加性背景和暗电流。
- detector noise。
- wavelength calibration shift。
- angle/polarization jitter。
- 材料 `n, k` 扰动。
- surface roughness effective loss。
- stray light。
- spectrometer resolution variation。

这意味着当前的漂亮指标必须加上边界条件：

> PCA50 + MLP 在当前仿真数据分布上可达到约 1-2 nm MAE，但尚不能直接代表真实实验指标。

### 4. 可部署输入与 oracle 输入必须严格区分

当前 ML 路线里最容易犯的错误是把仿真中知道、实验中不知道的量放进模型输入。

可部署输入：

- `L_fft_um`
- `film_nominal_nm`
- `spectra_norm_ds` 或其 PCA 特征
- 稳健光谱形状特征

不可作为主模型输入：

- `film_true_nm`
- `film_delta_nm`
- `cavity_true_um`
- `L_true_um`
- 任何由标签泄漏得到的字段

当前 PCA 报告里已经做了正确处理：PCA 只在 train set 上 fit，true thickness 和 target 字段未作为主模型输入。这个约束必须继续保持。

### 5. 数据划分与评估容易过于乐观

同一个 `process_id` 下会共享一组真实膜厚扰动。如果按 sample 随机划分，训练集和测试集会见到同一组工艺扰动，结果会虚高。

因此必须坚持：

```text
按 process_id 划分 train / val / test
PCA.fit(train spectra_norm_ds)
PCA.transform(train / val / test)
```

任何后续报告都要显式写清楚 split policy。

### 6. 实时处理和工程闭环仍未验证

如果方案目标指向高速调平或在线测量，则不能只看离线 MAE。

需要进一步回答：

- 光谱采集速度是否足够。
- `λ -> k` 重采样是否能实时完成。
- FFT、PCA/MLP 或 CNN 推理是否满足时延预算。
- 是否需要 FPGA、GPU、查表或批处理。
- 当峰归属失败、低可见度或薄膜信号淹没时，系统如何降级。

这个问题在论文里可以先作为“工程化边界”，但如果要做样机方案，必须变成验收指标。

## 下一步建议

### P0：先固定一个可验证主命题

建议当前阶段不要把问题写得过大。优先固定下面这个主命题：

> 在 StackRT 多层膜仿真数据中，仅使用真实实验可获得的输入 `L_fft_um + film_nominal_nm + 归一化光谱特征`，能否对膜层扰动造成的腔长误差做 nm 级残差补偿，并在未见 `process_id` 上保持泛化？

对应验收指标建议：

- 必须有 FFT-only、scalar baseline、PCA50 + MLP、CNN/ResNet 的对照。
- 必须采用 process-level split。
- 主指标看 MAE/RMSE/P95Abs/MaxAbs/Bias。
- 第一阶段目标：在干净仿真集上稳定复现 PCA50 + MLP 的 `1-2 nm` MAE。
- 第二阶段目标：加入 domain randomization 后，观察性能退化曲线。

### P1：做一份数据集与结果索引

现在 `work/03_ml_inverse_modeling/ML try/` 和 `wiki/04_Experiments/ML_Runs/` 已经有不少数据集、训练结果和报告。下一步最需要的是把“哪个结果来自哪个数据集”钉住。

建议新建或补充：

```text
wiki/04_Experiments/ML_Runs/ML实验索引.md
```

每个实验记录：

- 数据集路径。
- 数据集 shape、字段 keys、膜厚扰动范围。
- split policy。
- 是否保存 `spectra_norm_ds`。
- PCA 是否 train-only fit。
- 模型输入字段。
- 训练脚本路径。
- 输出指标。
- 结论和适用范围。

### P2：把 PCA50 + MLP 作为当前主 baseline

目前证据显示 PCA50 + MLP 是最强、最稳、最容易解释的路线。

下一步不建议直接跳 Transformer 或复杂 CNN。更好的顺序是：

1. 复现 PCA50 + MLP 结果。
2. 做 PCA20/PCA50/PCA100 消融。
3. 排除绝对强度敏感特征，比较 no-intensity 与 robust feature。
4. 再尝试 CNN-small / ResNet-1D。
5. 只有 CNN 明显超过 PCA50，才把 CNN 作为主路线。

### P3：做 domain randomization 小规模验证

建议先做一个小而清楚的扰动矩阵，不要一次把所有扰动都加进去。

第一批扰动建议：

- 光源强度缩放。
- 光源谱形倾斜或中心波长漂移。
- 加性背景。
- detector noise。
- wavelength calibration shift。
- spectrometer resolution variation。

第二批再加入：

- angle/polarization jitter。
- `n, k` 扰动。
- roughness effective loss。
- stray light。

每次只回答一个问题：

> 当前 PCA50 + MLP 对哪类真实扰动最敏感？

### P4：设计真实标定集的最小方案

真实数据不需要一开始很大，但要有代表性。

建议最小闭环：

1. 选 1-2 个简单 stack，最好包含裸硅参考或小空气腔参考。
2. 用椭偏仪或工艺记录拿 nominal/先验膜厚。
3. 用 AFM 获取少量绝对高度或局部台阶参考。
4. 如果需要膜层真值，再用 TEM 做少量截面样本。
5. 同步采集光谱，建立真实 `光谱 -> 高度/膜厚参考` 对。
6. 用仿真预训练模型做微调或误差评估。

这一阶段目标不是追求大样本，而是验证仿真模型的系统偏差。

### P5：把 CC + FP 混合方案转化为峰归属问题

如果继续推进混合型双通道方案，建议把它落成一个算法问题，而不是停留在概念图。

可写成：

```text
CC 通道：提供绝对高度粗窗和失锁重捕获。
FP 通道：在粗窗内做长腔峰检测、相位跟踪和残差补偿。
低 OPD 窗：用于估计薄膜项或提供薄膜约束。
峰归属状态机：用峰位、峰宽、幅度、相位稳定性、连续性和薄膜约束判断哪个峰对应上表面。
```

下一步建议新建方法页：

```text
wiki/03_Methods/Signal_Processing/CC_FP峰归属与状态机.md
```

核心内容：

- 高 OPD 长腔窗。
- 低 OPD 薄膜窗。
- 候选峰评分函数。
- 置信度和降级策略。
- 与 CC 粗测结果的 gating 关系。

### P6：明确哪些方向暂时不要优先做

近期不建议优先投入：

- LSTM/GRU/Transformer：当前光谱是波长序列，不是时间依赖序列，收益不明确。
- 直接预测所有膜层真实厚度：已有多输出实验显示空气腔 MAE 未明显改善，真实膜厚 oracle 对最终腔长提升也有限。
- 只凭仿真 MAE 直接写工程指标：真实扰动和真实标定尚未闭环。
- 只做掠入射概念而不处理有限光斑：StackRT 平面波模型不能输出光斑质心和横向偏移，掠入射路线需要额外模型。

## 可写成论文/开题的表述

可以把当前方向组织成三层贡献：

1. **物理建模层**：建立多层膜谱域干涉的 StackRT/TMM 正向仿真和 FFT 解算流程，分析膜层扰动导致的腔长偏差。
2. **数据驱动补偿层**：证明归一化光谱特征能够提供 scalar baseline 之外的膜层扰动信息，并用 PCA/MLP 做可解释残差补偿。
3. **系统架构层**：提出光谱共焦绝对定位 + FP 谱域干涉精测的混合方案，并给出峰归属、置信度和降级策略。

当前最扎实的是前两层，第三层还需要更多仿真和实验支撑。

## 待验证问题

- PCA50 + MLP 在 domain randomization 后是否仍保持 nm 级补偿能力？
- 当前 StackRT 数据的膜层参数范围是否覆盖真实工艺波动？
- 光谱归一化是否足以消除真实光源和探测器强度漂移？
- `n, k` 材料误差对残差模型影响有多大？
- 04/29 组会记录中“每一层厚度的测量误差值：10%左右”具体对应哪种测量手段、哪类膜系和哪种拟合模型？
- 少量真实标定数据是否能把仿真模型迁移到真实光谱？
- CC + FP 混合方案中，CC 负责粗窗还是也要参与膜层识别？
- 真实系统中长腔峰、薄膜峰和寄生峰能否稳定分离？
