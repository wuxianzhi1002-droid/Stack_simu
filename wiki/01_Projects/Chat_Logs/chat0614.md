现在我需要你新增一个完整验证脚本，建议命名为：

validate_prior_joint_fit_lumapi.py

目标：
使用 lumapi 调用 Lumerical 中真实的 PSS_TIO2_MODEL，不再使用简化合成光谱模型。通过真实 StackRT 或 Lumerical 仿真光谱，验证：

1. 当各膜层厚度存在 ±10 nm 不确定性时，固定线性标定参数是否会失效；
2. 固定膜厚非线性拟合是否能改善；
3. 带膜厚先验约束的“工艺级联合拟合”是否能进一步提高跨工艺鲁棒性。

核心思想：
不要每条光谱单独拟合膜厚。应对同一个工艺 process 下的一整组腔长扫描一起联合拟合。

对于第 p 个工艺，有多个腔长扫描点：

L_1, L_2, ..., L_N

同一工艺下的膜厚扰动是共享的：

Δd_1, Δd_2, ..., Δd_M

联合拟合变量为：

x = [L_1, L_2, ..., L_N, Δd_1, Δd_2, ..., Δd_M]

目标函数包括两部分：

1. 光谱残差：

r_spec = I_meas(lambda, L_i, d_nominal + Δd) - I_model(lambda, L_i, d_nominal + Δd)

2. 膜厚先验残差：

r_prior_i = Δd_i / σ_d_i

其中膜厚不确定性为 ±10 nm。默认把 ±10 nm 当作 3σ 范围：

σ_d_i = 10 / 3 nm

最终传给 scipy.optimize.least_squares 的残差为：

r = [r_spec_normalized, prior_weight * r_prior]

注意：
这里的 I_model 不要使用简化公式，而是通过 lumapi 修改 Lumerical 模型参数后运行真实仿真得到。

========================
六、baseline 2：固定膜厚非线性拟合
========================

实现函数：

fit_fixed_film_lsq(...)

思路：
- 膜厚固定为 nominal；
- 每条光谱只拟合腔长 L；
- 初值使用 L_linear_corrected；
- 边界设置为：

  L ∈ [L_init - fit_l_window_um, L_init + fit_l_window_um]

目标函数：
这里有两种可选实现方式，优先使用 A：

A. 如果 lumapi 调用速度可接受：
   每一次 least_squares 评估时，设置 L 和 nominal film thickness，调用 Lumerical 生成 I_model，再和 I_meas 比较。

B. 如果 A 太慢：
   先预计算或缓存 Lumerical 光谱查表，然后通过插值获得 I_model。
   建议先对每个 process 的膜厚和腔长点附近做局部查表。

注意：
由于直接在优化器每一步调用 Lumerical 可能非常慢，建议优先实现缓存机制：

model_cache[(L_um, film_tuple_nm)] = spectrum

或者先做离线网格，然后插值：

I_model = interpolate_spectrum(L, film_thicknesses)

第一版可以先只实现 A，代码结构预留 B。

光谱残差要归一化：
不要直接比较原始强度，否则光源包络和整体反射率会影响拟合。

建议：

normalize_spectrum(y) = (y - mean(y)) / (std(y) + eps)

残差：

r = normalize(I_model) - normalize(I_meas)

========================
七、主方法：带膜厚先验的工艺级联合拟合
========================

实现函数：

fit_prior_joint_process_lsq(...)

对每一个 process 单独做联合拟合。

输入：
- wavelengths
- spectra_process，shape = (num_cavity_points, num_wavelengths)
- L_init_array_um，由固定线性标定给出
- film_nominal_nm
- film_sigma_nm
- config

变量：

x = [L_1, L_2, ..., L_N, Δd_1, Δd_2, ..., Δd_M]

其中：
- N = num_cavity_points
- M = number of film layers

边界：

L_i ∈ [L_init_i - fit_l_window_um, L_init_i + fit_l_window_um]

Δd_j ∈ [-10, 10] nm

初值：

x0 = [L_init_1, ..., L_init_N, 0, 0, ..., 0]

目标函数：

对于每个腔长点 i：

film_current_nm = film_nominal_nm + delta_d_nm

I_model_i = lumapi_forward_spectrum(L_i, film_current_nm)

r_i = normalize(I_model_i) - normalize(I_meas_i)

拼接所有光谱残差：

r_spec = [r_1, r_2, ..., r_N]

膜厚先验：

r_prior_j = delta_d_j / film_sigma_nm

总残差：

r = concatenate([r_spec, prior_weight * r_prior])

输出：
- L_prior_joint_um，shape = (num_processes, num_cavity_points)
- delta_d_fit_nm，shape = (num_processes, num_film_layers)
- cost
- status
- nfev

重要：
同一个 process 下所有腔长点共享同一组 Δd_j。
不要每条光谱独立拟合 Δd_j。
