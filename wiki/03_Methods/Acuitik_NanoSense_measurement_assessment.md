# 悉识 NanoSense 测量原理、性能与需求适配评估

## 一句话结论

悉识 NanoSense / NS 系列本质上是宽谱反射式膜厚测量系统：用垂直入射宽波段光得到反射光谱，再通过反射率模型拟合或傅里叶算法反演膜厚、反射率和折射率。它比较适合作为当前项目的多层膜厚度先验、材料模型校准和 wafer / die 区域膜厚 mapping 工具；但不能直接等同于我们的长空气腔 FP 腔长解算传感器，除非厂商能提供原始光谱、采样间隔、波数重采样方式、拟合自由度和对 1 mm 级外腔条纹的验证结果。

## 当前测量需求口径

事实来源：`回复清华大学的问询.md` 和项目研究方案。

- 样品对象：硅片上的数十纳米至百纳米级复杂多层薄膜，包括介质膜、硬掩膜、光刻相关薄膜等。
- 部分样品可能存在表面图案结构，单个图案或 die 内区域可能不能用毫米级光斑平均。
- 项目更深层目标不是单纯输出膜厚，而是在膜层扰动存在时，从反射/干涉光谱中稳定解算 FP 腔长或顶面高度相关量。
- 现有方案把顶面高度粗先验控制在 `<=10 nm`，膜层误差更倾向于按工艺百分比建模，而不是统一写成固定 `±10 nm`。
- 对外部空气腔或长工作距离 FP 结构，已有理论页指出 `1 mm` 空气腔在 600 nm 附近的条纹周期约 `0.18 nm`，需要 `0.01-0.05 nm` 级采样或等效波数均匀采样才能可靠处理。

## 厂商资料中的测量原理

事实来源：`Acuitik_Products_v2.6_Chinese.pdf` 第 2-3 页、第 24 页；`案例2.pdf` 第 4、9 页。

### NanoSense 反射式膜厚测量

- 高稳定宽波段光垂直入射样品表面。
- 光在各膜层界面之间产生干涉，仪器采集反射光谱。
- 通过光谱分析和回归算法计算各层厚度；资料中把核心算法分成两类：
  - 薄膜测量：反射率最优化拟合算法。
  - 厚膜测量：傅里叶变换算法。
- 适用对象被描述为纳米级至微米级透明或半透明膜层，可输出厚度、反射率、折射率等参数。
- 案例 2 的界面说明显示，实际软件会同时展示反射率信号、厚度结果、FFT 变换后的厚度频谱信息和拟合曲线。

### EllipSense 椭偏仪补充路径

厂商手册还给出 EllipSense 椭偏测厚系统。其原理不是垂直反射强度拟合，而是斜入射偏振光后测量振幅比 `Psi` 和相位差 `Delta`，再建立光学模型拟合厚度、折射率 `n`、消光系数 `k` 和介电函数。

对当前项目而言，椭偏仪更适合作为材料 `n,k` 或部分膜厚先验来源，而不是替代 FP 腔长解算。若 NanoSense 对某些多层膜反演不稳定，椭偏仪可以帮助减少未知材料参数自由度。

## 厂商给出的关键性能

### NanoSense / NS-20 系列

事实来源：`Acuitik_Products_v2.6_Chinese.pdf` 第 7-10 页和问询回复。

| 项目   | 厂商资料口径                                                                     | 对当前项目的含义                            |
| ---- | -------------------------------------------------------------------------- | ----------------------------------- |
| 基本产品 | NS-20 为桌面式手动膜厚测量分析系统，拥有 NanoSense 系列算法软件功能                                 | 适合实验室点测和配方验证，不是自动全片量产 mapping 的首选   |
| 波长范围 | NS-20/UV/NIR/UVX/IRX 覆盖组合为约 `190-1700 nm`，具体型号不同                           | 宽谱有利于多层膜反演，但必须确认实际型号和可导出的原始谱段       |
| 厚度范围 | NS-20 不同型号约 `1 nm-80 um`、`15 nm-150 um`、`150 nm-250 um` 或 `1 nm-250 um`    | 覆盖数十到百纳米膜厚需求；不自动证明复杂多层每层都可辨识        |
| 准确度  | NS-20 表中常见为 `1 nm 或 0.2%`；UV Max / UVX Max 可到 `0.05 nm 或 0.1%`；NIR/IR 型号较低 | 数字来自特定标准样品口径，不能直接外推到含金属/吸收层/强相关多层膜  |
| 静态精度 | 表中为 `0.015-0.1 nm` 量级，取决于型号                                                | 更接近重复性/短期噪声，不等于绝对准确度                |
| 稳定性  | 表中为 `0.04-0.12 nm` 量级，取决于型号                                                | 说明标准片上短期或跨日统计较好，但仍需本项目样品验证          |
| 光斑   | 标准 `1.5 mm`；PB-Pro 探头 `0.2-1.5 mm`；NS-20 Pro 文案提到最小 `120 um`               | 对小图案区域仍偏大；若图案小于百微米，应考虑 NS-Micro     |
| 测量速度 | 单次 `<1 s`；AI+ 算法包可 `<10 ms`，取决于膜层材料                                        | 有潜力做快速点测，但复杂配方拟合速度需按真实 stack 验证     |
| 校准口径 | 厂商说明准确度以 Si/SiO2 标准片为基准；问询回复提到基于标准样品校准                                     | 必须要求厂商给出本项目膜系的交叉标定，而不能只看 SiO2/Si 指标 |

问询回复还补充：`~0.5 nm` 级测量精度为 `1 sigma` 统计口径，依赖样品平整度、粗糙度、材料纯净度和膜层间光学对比度；当两层材料在全谱段折射率偏差仅约 `0.01` 时，区分会很困难。

### NS-Micro 系列

事实来源：`Acuitik_Products_v2.6_Chinese.pdf` 第 16-17 页、问询回复。

| 项目 | 厂商资料口径 | 对当前项目的含义 |
|---|---|---|
| 定位 | 显微镜集成式膜厚测量分析系统，可实时显示测量点位图像 | 更适合图案区域、小 die 或定位测量 |
| 光斑 | 可选 `1-100 um`；15X 物镜配合孔径约 `7-33 um`，100X 可到 `1-5 um` | 若图案本身在 `1-200 um`，比 NS-20 更匹配 |
| 波长范围 | UV/Micro/UVX/IRX 组合覆盖约 `190-1700 nm` | 仍需确认所选物镜、孔径与谱段下的信噪比 |
| 厚度范围 | 典型为 `15 nm` 起，部分 UV/UVX + 15X 口径可到 `1 nm` 起；上限依型号和物镜约 `1-100 um` | 覆盖当前薄膜厚度，但小光斑下信噪比和模型稳定性需实测 |
| 准确度 | `1 nm 或 0.2%` / `2 nm 或 0.2%`，静态精度 `0.02 nm`，稳定性 `0.05 nm` | 对图案膜厚先验有价值；复杂 stack 仍要看可辨识性 |

### NS-HR / 厚膜路线

事实来源：`Acuitik_Products_v2.6_Chinese.pdf` 第 10、15 页。

NS-HR / NS30-HR 面向 `10 um` 至 `3 mm` 厚膜，仍基于光谱反射原理，但性能口径与 NS-20 薄膜型号不同：**厚膜准确度通常为 `50 nm 或 0.4%`**，重复精度约 `5 nm`。它能说明厂商有厚膜/长光程傅里叶测量路线，但不等于已经验证了带参考反射面的 `1 mm` 空气腔 FP 条纹解算。

原因是当前项目的 `1 mm` 空气腔并不只是透明厚膜厚度测量，还涉及外部参考界面、多层膜复反射、密集光谱条纹和波数域 FFT/拟合模型。需要厂商给出原始光谱采样和相干模型，否则不能直接套用 NS-HR 厚膜指标。

## 应用案例给出的证据

### 案例 1：玻璃基底薄膜/多层膜

事实来源：`案例1.pdf`。

- 样品包括两片多层膜、一个裸玻璃样品和七片单层膜样品；每个样品测上、下、左、右、中五个点。
- 单层膜案例覆盖 Si3N4、ZnO、Ag、NiCrOx、SiOxNy、Nb2O5 等，参考厚度从 `1-2 nm` 到 `25-40 nm`。
- 单层结果并非全部落入参考范围，例如：
  - Si3N4 参考 `15-30 nm`，测量范围 `6.31-14.14 nm`。
  - SiOxNy 参考 `25-40 nm`，测量范围 `37.49-49.75 nm`，部分偏高。
  - Nb2O5 参考 `2-4 nm`，测量范围 `1.39-2.56 nm`。
- 多层膜结果中，部分层与参考范围偏差明显，例如 6th layer SiOxNy 参考 `25-40 nm`，报告结果为 `3.46 nm` / `4.9 nm`；5th layer ZnO 参考 `7-13 nm`，报告结果为 `32.16 nm` / `28.61 nm`。

推断：这个案例对我们很重要，因为它说明“能拟合多层膜”和“每一层都达到 0.5 nm 准确度”不是一回事。对于含超薄金属、吸收层、低光学对比层或层间参数强相关的 stack，必须拿本项目样片做交叉验证。

### 案例 2：PI-Si 显微测量

事实来源：`案例2.pdf`。

- 设备为 NS-Micro，波长 `380-1050 nm`，测试中使用同一范围。
- 被测结构为 `PI膜-Si`，使用 15X 反射式镜头，光斑约 `17 um`。
- 单点单次积分测量时间 `<1 s`。
- 报告显示单个 die 上 PI 膜中心厚、边缘薄；附录给出每个点三次重复测量，厚度约 `6.7-10.7 um`。

推断：NS-Micro 对微区厚膜/聚合物膜测量是匹配的，尤其适合观察 die 内空间分布。但该案例的厚度是 `um` 级 PI 膜，不足以证明它对当前 `10-100 nm` 复杂多层膜、含硬掩膜/金属/光刻胶 stack 的逐层准确度。

## 与当前需求的适配判断

| 需求 | 适配等级 | 判断 |
|---|---|---|
| 平坦硅片上单层或少数层透明/半透明膜厚测量 | 高 | 原理和规格匹配，厚度范围覆盖，标准片口径下重复性较好 |
| 数十至百纳米多层膜的膜厚先验获取 | 中-高 | 适合作为候选工具，但必须固定层序、材料库和部分参数，并做本项目样片标定 |
| 含图案区域的局部膜厚测量 | 中 | NS-20 标准光斑过大；NS-Micro 的 `1-100 um` 光斑更合适，但小光斑信噪比要验证 |
| 含金属/吸收层/硬掩膜的复杂 stack 逐层反演 | 中-低 | 厂商资料声称材料库覆盖部分金属/金属化合物，但案例 1 显示多层拟合可能明显偏离参考范围 |
| 未知材料 `n,k` 与未知层厚同时反演 | 低 | 问询回复也承认已知 `n,k` 时精度最佳；未知材料应配合材料库、客户提供常数或椭偏建模 |
| 为当前 FP 腔长解算提供膜厚/材料先验 | 高 | 可作为独立计量输入，帮助收缩膜层扰动范围和材料模型自由度 |
| 直接替代当前长空气腔 FP 腔长传感器 | 低/未证实 | 厂商资料没有给出 1 mm 外腔密集条纹、原始谱采样和相位模型验证 |
| 支撑 `<=10 nm` 顶面高度先验 | 未证实 | NanoSense 测膜厚，不直接给表面绝对高度；若要高度先验，需要另行确认测量几何或搭配轮廓/共焦/干涉高度设备 |

## 对项目的推荐使用方式

### 第一用途：膜厚先验工具

建议把 NanoSense / NS-Micro 定位为膜厚先验来源之一，而不是最终腔长解算器。可输出：

- 每层或等效层厚度的名义值和不确定度。
- wafer / die 内膜厚分布，用于替代仿真中拍脑袋的百分比扰动。
- 某些材料体系下的反射率谱形，用于校正 TMM/StackRT 正向模型。

### 第二用途：材料模型约束

对未知或供应商材料，优先要求：

- NanoSense 拟合中使用的材料库名称、`n,k(lambda)` 来源和版本。
- 是否允许导入客户自定义 `n,k`。
- 同一 stack 是否能用 EllipSense 或第三方椭偏/XRR/TEM 建立 `n,k` 与厚度先验。

### 第三用途：图案区域局部验证

若样品图案在 `1-200 um` 范围，应优先评估 NS-Micro，而不是 NS-20 标准光斑。验收时要明确：

- 光斑直径相对于图案 CD、pitch 和测量区域是否足够小。
- 小光斑下的反射信号是否仍能稳定拟合。
- 测点定位误差是否会导致跨图案平均。

## 采购或送样验证前应索取的信息

1. 多层膜 `0.5 nm` 或亚纳米准确度对应的真实测试样品结构、材料、层数和每层厚度范围。
2. 对本项目 stack，哪些层固定，哪些层自由拟合，哪些材料 `n,k` 固定，哪些材料参数可拟合。
3. 原始光谱是否可导出，包括波长数组、反射率、暗场/参考归一化前后数据。
4. 光谱采样间隔、光谱分辨率、波长标定误差和是否支持等波数重采样。
5. 拟合输出是否包含 GOF、残差曲线、参数置信区间、参数相关矩阵和多解提示。
6. 对金属层、强吸收层、粗糙界面、梯度折射率和图案区域的模型处理方式。
7. 标准片校准流程、校准频率、跨日稳定性定义，以及是否能用本项目标准样片重新建配方。
8. NS-Micro 小光斑模式下，实际可用 NA、工作距离、光斑、谱段和信噪比如何相互制约。
9. 若用于外腔或厚膜傅里叶测量，是否有 `1 mm` 空气腔或等效 OPD 的原始光谱和解算报告。

## 建议验收实验

### A. 平坦区多层膜厚交叉验证

- 选择 3-5 片代表性 stack，覆盖透明介质、硬掩膜、光刻胶、有吸收层/金属层的情况。
- 每片至少测中心和四角，记录 NanoSense 原始谱、拟合曲线、残差和厚度结果。
- 用椭偏、XRR、TEM 截面、AFM 台阶或工艺计量结果作为参考。
- 输出每层误差，而不是只输出总膜厚或 GOF。

### B. 重复性与重装夹稳定性

- 同一点连续测 `100` 次，得到短期 `1 sigma`。
- 样品取下重放至少 `10` 次，得到装夹/定位误差。
- 跨日重复测标准片和项目样片，验证厂商稳定性指标是否能迁移到本 stack。

### C. 图案区适配实验

- 用 NS-Micro 对同一 die 内不同图案区域、阵列区域和大面积 open 区分别测量。
- 比较不同物镜和孔径下结果是否一致。
- 确认测量结果是否随光斑覆盖图案比例系统漂移。

### D. 对 FP 腔长解算的辅助价值

- 将 NanoSense/椭偏得到的膜厚先验输入当前 TMM/StackRT 模型。
- 比较使用名义膜厚、NanoSense 先验、椭偏/XRR 先验时，FP 腔长反演误差和锁错峰比例的变化。
- 如果厂商能导出原始宽谱反射率，也可与本地 TMM 计算做 forward-model mismatch 检查。

## 风险与边界条件

- 厂商准确度、精度、稳定性常以 SiO2/Si 标准片定义，不能直接代表复杂多层膜逐层准确度。
- 多层膜反演的主要风险是不可辨识性：低光学对比层、强吸收层、超薄层和相邻层参数相关都会造成多解。
- 光斑平均会掩盖图案区真实局部差异；NS-20 标准光斑尤其需要谨慎。
- 如果材料 `n,k` 不准，拟合可能用错误厚度补偿材料误差。
- 单次 GOF 高不代表参数唯一；必须看残差、置信区间和参数相关性。
- NS-HR 厚膜能力不能自动推导为 `1 mm` 外腔 FP 位移测量能力。

## 阶段性结论

建议把悉识设备评估为：

> 适合作为膜厚/材料先验和局部验证工具；暂不应作为当前长腔 FP 解算路线的直接替代方案。

优先级建议：如果预算或送样机会有限，先让厂商用 NS-Micro 或合适的 NS-20/UVX 型号测试本项目真实 stack，并要求交付原始光谱、拟合残差和参考计量对比。只有当真实 stack 上逐层误差、重复性和跨日稳定性达到需求后，才把其输出纳入 FP 腔长反演先验。
