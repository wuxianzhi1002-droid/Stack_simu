现在需要新增一个独立脚本：

    extract_pca_features.py

位置：

    01_Lumerical_Workflow/ML try/Residual MLP/extract_pca_features.py

目标是：

    从大 NPZ 中读取 spectra_norm_ds，
    只在 train split 上 fit PCA，
    transform 全部样本，
    保存轻量 PCA 特征 NPZ，
    后续 MLP 训练直接读取这个 PCA 特征文件，而不是每次重新读取 5~7GB 的 spectra_norm_ds。

============================================================
一、核心原则
============================================================

1. PCA 只能在 train set 上 fit。
2. val/test 只能 transform，不能参与 fit。
3. 不能对全数据 fit PCA，否则数据泄漏。
4. PCA 输入使用 spectra_norm_ds。
5. PCA 输出保存为 pca_scores。
6. 默认只 fit 一次 PCA(n_components=100)，后续训练时可以使用前 20/50/100 个分量。
7. 不在 extract_pca_features.py 中训练 MLP。
8. 原始大 NPZ 不修改，只生成新的 PCA 特征 NPZ。

============================================================
二、输入输出路径
============================================================

输入参数：

    --dataset path/to/nn_cavity_spectral_features_*.npz
    --output-dir path/to/output_dir
    --n-components 100
    --max-pca-fit-rows 100000
    --random-seed 20260613
    --batch-size 20000
    --pca-method randomized
    --overwrite false

默认：

    n_components = 100
    max_pca_fit_rows = 100000
    random_seed = 20260613
    batch_size = 20000
    pca_method = randomized

如果 --output-dir 不指定，则默认在数据集同级目录下创建：

    pca_features/

输出文件名：

    nn_cavity_pca_features_100_YYYYMMDD_HHMMSS.npz
    pca_summary_YYYYMMDD_HHMMSS.json
    pca_explained_variance_YYYYMMDD_HHMMSS.png

============================================================
三、split 规则
============================================================

优先使用数据集已有的 split_id：

    split_id == 0 -> train
    split_id == 1 -> val
    split_id == 2 -> test

并且 valid_mask 必须为 True。

如果 split_id 不存在，则使用 train_process_ids / val_process_ids / test_process_ids 生成 split_id。

要求输出检查：

    train rows
    val rows
    test rows
    train process count
    val process count
    test process count
    process overlap between train/val/test

process overlap 必须为 0。

============================================================
四、PCA fit 逻辑
============================================================

数据集中 spectra_norm_ds 很大：

    shape = (800000, 2000)
    dtype = float32

不要一次性复制成 float64。

读取后尽量保持 float32。

fit PCA 时：

1. 从 train_indices 中随机抽取最多 max_pca_fit_rows 行。
2. 使用 sklearn.decomposition.PCA：
   
   PCA(
       n_components=args.n_components,
       svd_solver="randomized",
       random_state=args.random_seed
   )

3. 只用抽样 train spectra fit PCA。
4. fit 后分 batch transform 全部样本，避免内存峰值太高。
5. transform 结果保存为 float32。

如果 max_pca_fit_rows 为 None 或 <=0，则使用全部 train rows fit PCA。

注意：
PCA 本身会在 fit 内部计算 mean，因此不要手动用全数据计算 mean。
也不要用 val/test 的光谱参与 PCA mean 或 components 的计算。

============================================================
八、内存与速度要求
============================================================

1. spectra_norm_ds 不要整体 astype(float64)。
2. PCA scores 用 np.memmap 或分 batch transform，避免一次性生成过大中间数组。
3. transform 时按 batch_size 分块：

       for start in range(0, num_samples, batch_size):
           X_batch = spectra_norm_ds[start:end].astype(np.float32, copy=False)
           scores[start:end] = pca.transform(X_batch).astype(np.float32)

4. 如果输出目录中已有同名文件且 overwrite=false，则报错，不覆盖。
5. 运行时打印进度：

       Loading dataset...
       Split check...
       Fitting PCA...
       Transforming batch 1/N...
       Saving PCA NPZ...
       Summary saved...
       Done.
